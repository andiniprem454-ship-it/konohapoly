# Konohapoly — Monopoli Bertahan Hidup di Negeri Konoha

Game monopoli satire Indonesia 3-4 pemain online (multiplayer realtime & bot AI).

### 🚀 Cara Deploy ke Vercel:
1. Upload isi folder ini (atau push ke repo GitHub baru, misal `konohapoly`).
2. Import project di **Vercel** sebagai static site.
3. Langsung online di `https://<nama-project>.vercel.app/`.

### 🛡️ Kode Admin:
- Masuk ke lobby > klik **🛡️ Saya admin** > masukkan kode:
  - `konoha6283` (atau `admin6283` / `bzkriptot`)
- Atau ketik di chat: `/admin konoha6283`.

### ⚡ Fitur Standalone:
- Langsung terbuka di root `/` (tanpa subfolder `/konohapoly.html`).
- Auto-delete room selesai (room otomatis terhapus saat game berakhir).
- Support bot offline & multiplayer online via backend/Supabase.
